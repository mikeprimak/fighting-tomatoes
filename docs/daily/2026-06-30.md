# 2026-06-30

## Published held Home-reorder production OTA (store builds now live)

The Home-screen reorder (`d4095d05`, 2026-06-29) had its production OTA **deliberately held** while new 2.1.3 store builds were in review at both stores (see `HANDOFF-home-reorder-ota-pending-2026-06-29.md`). Mike confirmed both builds are now approved/live, so the OTA was published.

### Pre-publish verification
- Confirmed `d4095d05` (reorder) is an ancestor of HEAD (`24930836`) — checkout has the code.
- `packages/mobile` working tree clean (untracked files at repo root are logos/docs/infographics only — not bundled).
- Version match: new store builds are **2.1.3** (`13ba1be5`: iOS bn23 / Android vc40). Project config resolves iOS runtime → `2.1.3` (appVersion policy) and Android runtime → `1.0.0` (hardcoded in `app.json`). Matches the new builds. ✅
- Note: the 2.1.3 version bump (`13ba1be5`) landed **before** the reorder commit (`d4095d05`), so the 2.1.3 native builds do **not** contain the reorder — this OTA is what delivers it to them.
- `eas update:list` confirmed prior live runtimes were iOS `2.1.2` / Android `1.0.0`.

- **Android:** single runtime `1.0.0` → all Android users (old vc38 + new vc40) get the reorder in one shot.
- **iOS:** OTA targets `2.1.3` only. iOS users still on `2.1.2` are **not** reached by this update (inherent to the appVersion runtime policy) — they'll get the reorder when they update to 2.1.3.
