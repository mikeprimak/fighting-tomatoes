# 2026-07-04 — Home screen polish sweep (web + mobile), shipped same-day

## What shipped

Nine home-screen edits across web and mobile (main branch — the user-focused-pivot home was NOT touched), pushed to prod today.

### Web home (`packages/web`)

1. **Event banners on fight sections** — "Hyped Upcoming Fights" and "Recent Good Fights" now group fights under a banner header (event poster, top-anchored crop, gradient, name + when), mirroring the mobile `HypedEventCard`. The banner links to the event detail page; the fight cards inside keep their existing click-to-open-modal behavior (explicit Mike requirement). New `EventBanner` / `EventFightGroup` in `src/components/home/FightSections.tsx`.
   - **Recent Good Fights switched data source**: `getTopRecentFights('month')` → new `getRecentGoodFights()` (`/community/recent-good-fights`, the endpoint mobile already used: 14-day window, ≤3 events, ≤3 fights/event). Content now matches mobile exactly. `showRank` dropped (grouped UI).
2. **"Top Comments" renamed** → "Comments on Recent Fights" (`CommentSections.tsx`).
3. **"Recently Booked" renamed** → "Recently Booked Fighters" and moved above Highlighted Fighters (`FighterSections.tsx`, `HomeClient.tsx`).
4. **Highlighted Fighter → Highlighted Fighters rail** — the single big card is gone; now a side-scrollable rail of compact portrait cards (`FeaturedFighterCard`), consuming the `fighters` array the backend already ships on `/community/highlighted-fighter` (falls back to `[data.fighter]`). Mirrors mobile.

### Mobile home (`packages/mobile/app/(tabs)/home.tsx`)

5. **"This Week" empty state removed** — when there are no events in the window the section renders nothing (was: "No events in the next 7 days" card). Matches web.
6. **HYPE / RATING column headers** — `HypedEventCard` now renders a small right-aligned column label over the heatmap score boxes ("HYPE" on Top Upcoming Fights, "RATING" on Recent Good Fights).
7. **Comment cards width-aligned** — "Comments on recent fights" cards were full-bleed; now wrapped with 16px horizontal padding so they share the event cards' screen-edge margins.
8. **"Most Followed" renamed** → "Most Followed Fighters".
9. **Classics throwback comment reworked** (corrects a misunderstood earlier directive): the standalone old-fight `CommentCard` at the bottom of "Classics to Watch" is REMOVED. Instead, each classic fight card can show its own standout comment right below the `CompletedFightCard` — body only, italic, 2 lines max with ellipsis, no username/upvotes. Taps through to the fight.

### Backend (`packages/backend/src/routes/community.ts`)

- `/community/classic-fights` now includes each fight's top comment: most-upvoted top-level review with non-empty content → `topComment` (string | null). Raw `reviews` relation stripped from the response. Verified locally against prod DB (topComment populated where reviews exist, null otherwise). Mobile handles `topComment` absent/null, so OTA and backend deploy order doesn't matter.
